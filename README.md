# Aplikasi Kopi dan Nyemil

Aplikasi mobile berbasis Android (Kotlin & Jetpack Compose) untuk pemesanan kopi dan makanan ringan (nyemil). Aplikasi ini dibuat guna memenuhi Ujian Tengah Semester (UTS) Mata Kuliah Pemrograman Mobile.

## Fitur Utama Aplikasi
1. Splash/Welcome Screen: Halaman pembuka aplikasi saat pertama kali dijalankan.
2. Autentikasi (Login & Register): Halaman masuk dan pendaftaran akun pengguna baru.
3. Home Screen (Daftar Menu): Menampilkan sapaan pengguna, kategori produk, serta minimal 5 item menu makanan dan minuman lengkap dengan harga, deskripsi, dan rating.
4. Alamat Pengiriman: Formulir pengisian alamat lengkap tujuan pengantaran dan catatan kurir.
5. Konfirmasi Pesanan: Ringkasan rincian pesanan dan total pembayaran sebelum pesanan diproses.
6. Profile Screen: Halaman informasi akun pengguna, NIM, serta riwayat pesanan singkat.

## Teknologi yang Digunakan
